# Changelog

All notable changes to Delta are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

## [1.3.1] - 2026-11-14

### Added
- AGPL-3.0 licence, a `NOTICE` for the name, icon and Formula 1 material, and a contributing guide
- Two build flavors: `direct` (the GitHub APK) and `play` (no support link)
- A short support note at the bottom of Home in the `direct` flavor, plus the unofficial-app line
- Install steps in the README

## [1.3.0] - 2026-11-14

### Added
- News tab with eight press feeds in a lead-and-wire layout and a Reddit tab for r/formula1,
  r/formuladank and r/f1discussion
- Team page hero with the team's real 2026 car in a stripe band
- A new app icon: a racing line with a red apex

### Changed
- Polish pass: sliding-thumb bottom bar and toggles, press feedback, season picker as a bottom
  sheet, skeleton loading, count-up stats, collapsing titles, pull to refresh, haptics,
  predictive back and reduced-motion support
- Compose BOM updated to 2024.09.03

## [1.2.0] - 2026-11-14

### Added
- Three tabs (Home, Championship, News), each with its own back stack
- Championship tab with Drivers and Constructors tables, a season selector back to 1950 and a
  champion marker on past seasons
- Race result page with the full classification for any finished round
- Circuit page and race weekend page with a 3D track, derived length, laps, turns, local-time
  sessions and the winner of every race held there
- Driver and team depth: career totals, teammate head-to-head, recent results, points by round
  and season history
- One optional race reminder notification an hour before lights out
- A "Season complete" state on Home after the final race

### Changed
- The package is now `dev.anpo.f1`
- The app is F1 only. The earlier Tasks and Valorant plans were dropped

## [1.1.2] - 2026-07-18

### Fixed
- Carbon-fibre fill, engrave and stroke restored on the hero race number

## [1.1.1] - 2026-07-18

### Fixed
- Hero number rework and an occlusion fix

## [1.1.0] - 2026-07-18

### Added
- Calendar, constructor page and the next circuit on Home
- Inter typeface and a new icon

## [1.0.0] - 2026-07-18

First signed release: the F1 tab.
